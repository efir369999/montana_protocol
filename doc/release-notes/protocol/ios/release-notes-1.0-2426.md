1.0 (2426) Release Notes
========================

MT Protocol for iPhone, iPad and Mac, build 1.0 (2426), from source commit `1f3181e852daa7c68038721b03d477c2b0b7c89d` of 2026-11-17. The folder `apps/protocol/ios` of this repository holds that tree as it is built.

Notable changes
---------------

- What you put into Saved Messages on one of your devices now goes to your other devices at once over the live connection they already hold, instead of standing in a relay's queue; a device that sleeps still gets it the way it did.
- Everything in Saved Messages now looks the same on all your devices: an edit, a reaction or a deletion on one device shows on the others, a forwarded photo or file arrives there too, and replies, link cards, forwards and albums keep their look.
- When notifications are off, a small red badge now sits on the corner of the time symbol instead of a circle beside it.

Security and anonymity
----------------------

- Security and anonymity are unchanged: the word travels sealed by a key only your own devices hold, in the same form and size as any letter, under a label that changes every minute and names nobody; whoever carries it sees neither what it says nor whose it is.
- Security and anonymity are unchanged: the change travels sealed by a key only your own devices hold, by the same road a new entry already takes; nothing new is said to anyone else.
