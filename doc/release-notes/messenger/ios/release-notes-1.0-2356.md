1.0 (2356) Release Notes
========================

Montana for iPhone, iPad and Mac, build 1.0 (2356), from source commit `f2f132e5de20a0f79ccdf34726089754ac8b53e6` of 2026-11-04. The folder `apps/messenger/ios` of this repository holds that tree as it is built.

Notable changes
---------------

- The card with your contacts that you send in a chat is now called a contact card.

Security and anonymity
----------------------

- Only names inside the code and one English word on screen change.
- No new server, network road or key leaving the device.
